# About

LearnWith Mahidhar is a free study guide for developers preparing for Java, Spring Boot and Microservices interviews.

Instead of memorising question lists, each page explains how things actually work (HashMap internals, how auto-configuration decides what to create, why a saga needs compensation) and then shows the questions interviewers ask about them, with model answers.

## How the content is organised

- **Topic sections** go from Core Java through Spring, data, microservices, messaging, security and DevOps.
- **System design** pages apply the ideas to realistic Java microservice scenarios.
- **Interview toolkit** collects question banks, coding problems, behavioural answers and cheat sheets.

## Accuracy

Code samples are written for recent Java and Spring Boot versions and checked before publishing. If you spot a mistake, please [get in touch](/contact).
